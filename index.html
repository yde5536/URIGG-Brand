칸은 꽤 투명하지만 완전히 맑지는 않습니다. 뒤 오로라가 흐리게 비치고, 테두리는 얇은 빛 한 줄, 위쪽에만 은은한 반사광이 있습니다.

유리 칸

더 보기 ↗
  • 바탕rgb(18 20 26 / 0.16)
  • 흐림blur(10px) saturate(170%)
  • 모서리26px
  • 안쪽 여백18px 22px

칸 제목을 탭으로 쓸 때: 고른 탭 뒤로 유리 알약이 미끄러집니다 (420ms, 살짝 튀는 곡선). 눌러 보세요.

부품

유리 아이콘 · 버튼

Claude GitHub 드림핵 티스토리
Windows 다운로드 주요 버튼(크림슨)은 한 화면에 하나쯤. 나머지는 유리 알약.
  • 아이콘은 흰색 단색입니다 (icons/, simple-icons CC0, 드림핵은 공식 로고의 심볼만). 브랜드 원색은 쓰지 않습니다.

움직임

  • 누를 때100ms · scale(0.95)
  • 보통 전환200ms · cubic-bezier(0.16, 1, 0.3, 1)
  • 버튼 떠오름240ms · cubic-bezier(0.34, 1.56, 0.64, 1)
  • 탭 알약420ms · cubic-bezier(0.3, 1.4, 0.5, 1)
  • 오로라58 · 67 · 74초 주기, 초당 8번만 옮김
  • 애니메이션 줄이기설정이 켜져 있으면 움직임을 모두 끕니다.
